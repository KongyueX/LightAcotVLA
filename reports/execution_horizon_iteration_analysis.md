# Predictor A：迭代结果与下一步研究判断

2026-09-08。依据已有完整实验与论文原文进行分析，未启动新训练、采集、评测或额外审计。当前仍保留Round4两层global ordered Transformer A。

## 总体判断

A已学到有效的动态执行策略，但后续尚未找到可替换它的版本。现有结果更支持优先研究监督信号、策略改变后的完整回报与执行中的新反馈，而不是继续增加层数或重复末端小头。这个优先级是研究判断，不是已证明的故障归因。

## 结果支持什么

1. **动态H仍有用。** 同200局，θ0到A由177提高到189成功；同H25的Fixed H5为190成功，RPC为6.053秒，A为1.901秒。A保住了大部分观察成功数，同时显著减少计算。1000局完整系统结果为H25＋A 913/1000，对原版历史927/1000，记录的RPC减少68.81%、整局减少30.21%；这是完整系统与历史记录的比较，不能全部归因于predictor。[1000局结果](execution_horizon_current_vs_original_10x100.md)
2. **局部指标改善反复没有转化为闭环改善。** 最新query早停缓存净多5/300次成功，但完整闭环比本批A少1/100；critic拟合、候选head验证loss、greedy选模也出现类似现象。9000分支对应300个训练root和60个早停root，不能当作9000个独立状态。
3. **主要时间损失伴随调用和轨迹变化。** 最新query和hidden都增加调用次数；不能把总RPC增长直接归因于新增小模块。1000局中predictor约占整局0.9%，单纯压缩sidecar不足以解决成功率问题。
4. **没有统一短H或长H规则的证据。** 9组差异回放有8组复现；有效单H介入中保留history首H为22/24，改回A首H为20/24。同样的提前重规划既有救回也有退化。另在200局A/H5比较中，两者相互救回9/10局，事后成功并集为199/200；这仅说明策略结果互补，不是可部署成功率或新实验。
5. **Hidden尚未被有效的非零增量检验。** 它训练650步后选中step0，88/100不能解释为“学到hidden后变差”。同bank的A跨运行出现93与90，也限制了对1–2局变化的归因；应使用同批A，并尽量保持动作生成路径一致。

## 论文机制与本项目的对应关系

以下BCP、DEHP、ACH、TempoWAM及Knowing When to Stop均按2026年预印本引用；AutoHorizon的arXiv元数据注明ECCV 2026。

| 论文 | 可借鉴的机制 | 与当前实验的关键区别 |
| --- | --- | --- |
| [BCP，Xu等](https://arxiv.org/html/2608.03483) | 有序continuation；同任务实例多条自适应完整轨迹加一条固定H参考，以组相对回报训练；成功条件化的效率奖励 | A已有有序输出形式，但9000分支是一次改H、后续A接力。已有PPO也没有复现这种reference-group估计；论文主要按calls奖励，改成实测RPC是本项目适配 |
| [DEHP，Zhao等](https://arxiv.org/html/2606.11408v2) | 冻结动作策略，SMDP PPO学习当前H策略的完整回报，critic预热及分布式价值表示 | 普通PPO与预热已经试过；论文实验用含物体状态的state observation，没有本项目的RPC约束，不能直接继承其增益 |
| [ACH，Shin等](https://arxiv.org/html/2605.10044v1) | 因果地估计每个动作前缀的Q，并使用对应中间状态进行多步TD更新 | 候选读取B/R没有实现该价值目标；论文还联合训练动作策略，冻结VLA的适配需要自己的证据 |
| [TempoWAM，Ye等](https://arxiv.org/html/2608.09492) | 执行短前缀后，结合新观测、剩余动作和GRU历史判断继续或重新规划 | A及本批两个模块都在调用开始时决定H。论文monitor无需未来视频想象，但依赖新的视觉编码、进度监督与校准；其时间进度标签有单调性/状态混叠限制 |
| [AutoHorizon，Wang等](https://arxiv.org/abs/2602.21445)；[Knowing When to Stop，Xu等](https://arxiv.org/html/2609.00908) | 动作自注意力或动作到视觉token的注意力变化，用于推理时截断 | 注意力统计不是本批的1024维hidden投影，也不是经过校准的成功概率；仍在推理时判断，不能替代执行中读取新观测 |

BCP中值得优先借鉴的是完整轨迹组与参考回报，而不只是其continue/stop参数化。它把失败轨迹奖励设为0，再在成功轨迹中考虑相对效率；这避免奖励廉价失败，但不等于从数学上保证最大化总体成功率。本项目仍应以实际闭环成功数和耗时选择模型。

ACH的核心目标可以概括为：

\[
Q(s,a_{1:k})\leftarrow\sum_{j<k}\gamma^j r_j+\gamma^k V_{\pi}(s_k).
\]

关键是每个前缀有对应的中间状态，且价值跟随当前策略；仅为H5/H10等增加不同query或head并不等于实现了它。

## 下一步优先级

### 1. 主线：以A为整局参考，改善策略回报与更新信号

保持A的结构和动作模型，围绕同一训练初态采候选自身控制全程H的若干轨迹，并保留A的完整参考轨迹；用组相对回报更新已有actor，减少对尚不稳定critic的依赖。与旧单点标签相比，它直接评价候选全程产生的状态分布；与已做PPO相比，新变量是同初态参考组和优势估计，不是再加epochs。

Q^A并不是错误标签，它合理评价了“此刻改H、之后A继续”。需要验证的是这种局部排序能否在候选全程控制时保持。可先用少量训练root比较A接力与候选接力下的H收益；若经常反转，就有依据更新continuation与采样分布，若不反转则不能把它当主要解释。不要直接再次投入同规模9000分支。

### 2. 决策结构主线：让停止时机利用执行中的新反馈

A给出候选执行长度，执行若干步后由轻量监视器读取新状态，判断继续剩余动作还是触发新VLA调用。它针对的是执行后才出现的接触、滑动、停滞等信息，当前query、hidden和单次历史差分无法替代这一信息时序。

适配TempoWAM时保留实际观测和全局信息，初步聚焦已有结果中的Task3/4/6/9风险阶段，同时在完整任务集合评估。不能把“过了更久”当作“任务进展更多”，也不能假定监视器免费；视觉编码与额外调用必须计入实际耗时。

### 3. 小幅结构补充：利用已学好的动作输出投影

可将缓存的末次expert hidden经过冻结的`action_out_proj`，得到动作维度对齐的末次flow velocity，再与现有动作特征结合；代码关系为`v_t = action_out_proj(final_hidden)`。这不同于A已有的动作序列相邻差分。已有hidden、normalized action及模型权重可支持离线派生，不需要新增VLA前向或再采9000分支。

BCP文字中使用末次去噪的action-velocity feature提供了设计动机，但具体采用输出投影后的低维向量是本项目提案，不能称为已完成的BCP复现；论文未给出该输入的单项消融。Flow velocity不是机械速度，其幅度也不能直接当置信度。相比重新学习任意1024维投影，该方案检验的是已学好的动作输出坐标是否更适合当前小样本监督。

## 不优先继续的方向

目前不优先加深Transformer、重复候选H读取头、增加同类PPO轮数、扫描时间惩罚系数或统一缩短H。注意力特征、真实多步记忆及动作专家恢复训练仍是可选方向，但应分别对应可验证的缺口；现有结果没有支持同时叠加多个模块。

## Limitations

本分析复用已有结果与区间，没有增加独立测试证据。多批开发集复用与跨运行变化使小幅差异难以归因；hidden step0尤其不能用来否定整个内部特征方向。论文大多为预印本，其数据、基础策略、输入、奖励和计算环境与本项目不同。前缀价值、参考组训练及执行中监视器均为后续建议，尚未在本项目启动或验证。
