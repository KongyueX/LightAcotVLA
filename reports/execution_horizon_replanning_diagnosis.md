# A与历史小头：重规划差异诊断

2026-09-08。先判断已完成开发对照中的成败差异，再据证据选择一个改进方向。原A、H25和已训练历史小头均保留，当前不改变动作生成或H选择。

## 第一阶段：相同初态被动回放

回放历史小头相对A的全部5个退化局、4个救回局，共9对18局：

| 类型 | Task / episode |
| --- | --- |
| 退化 | 3/339、6/339、8/338、8/343、9/345 |
| 救回 | 0/344、2/336、4/337、7/339 |

沿用原bank、seed7、NFE10/10、等待10步、resize224，以及两模式在原交错评测中的相对执行顺序。每次policy call和env.step补录实际数据，不增加policy调用或额外观测：

- 当前完整生成动作、原A建议H、实际选择/执行H、决策环境步与原seed。
- 末端位置/姿态、夹爪状态、实际执行动作、可用物体状态；物理快照仅作诊断。
- 复用已有agentview图像记录视频及少量决策帧。

先单列原成败是否复现。按绝对环境步对齐，共同前缀内检查状态、生成动作与seed一致性；首次H分歧之后再观察动作和状态怎样分开。动作向量差分称作命令变化，不冒称实际物理速度。记录功能引入的耗时不作为新速度成绩。

## 判断方式

对每局报告新旧chunk重叠区间的计划差异、边界命令变化和实际末端运动，再按episode等权汇总。单个较大跳变只能作为线索，不能直接定为失败原因；首次H分歧与最终成败之间也可能存在多个后续决策。

若回放可复现且差异集中于重规划边界，下一步优先做少量同状态介入，区分重新观察时机与旧计划接续的影响，再决定是否训练动作接续。若边界证据弱，转向候选自身整局回报/信用估计；若多个H在同状态都难恢复，检查更早偏差及恢复动作。只推进有证据支持的一项，不并行堆叠新模块。

这9个开发初态用于诊断，不转为梯度训练样本；后续训练使用训练初态，未使用的预留测试保持独立。判断和具体推进结果追加到本文件。
